Program Control

-- DESCRIPTION --

ProgramControl is the "glue" between the other teammates and is the avenue through which their code will interact.
After the user interacts with the CLI and User Interface parses through arguments, User Interface will construct a
ProgramControl instance and call the method respective to the amount of arguments provided.

listFiles():
When no arguments are given, UserInterface should call this method. listFiles() asks for a directory of files from
the File Handler. The program should then return a list of all available files, with the file number and associate
title.

defaultDecipher( int fileNum ):
When there is one argument given, UserInterface should call this method. defaultDecipher takes one argument, an int
indicating the file number the user wishes to access. The program should cast the int into a string and request file
contents from the FileHandler. Upon return of the deciphered message associated with the given file, Program Control
returns the deciphered string to User Interface. If the file number is invalid, Program Control returns an error
message.

specialDecipher( int fileNum, String key ):
When there are two arguments given, the program should request file contents from the File Handler and provide it with a
specified alternate key to use when deciphering. If the file number or alternate key is invalid, Program Control returns
an error message. If the deciphered message is returned successfully, Program Control returns the deciphered string.

-- TESTS --

* .listFiles() should return the list of files if such a list exists. returned string should have at least one line
with a leading number and respective title.

* .listFiles() should return a clean error message if there is no directory to be found.

* .defaultDecipher() should return expected plaintext for a given file using the default key.

* .defaultDecipher() should return a clean invalid file error message when the fileNum is invalid (both above or below).

* .specialDecipher should return expected plaintext for a given file using the special key.

* .specialDecipher should return a clean invalid file error message when the fileNum is invalid.

* .specialDecipher should return a clean invalid key error message when the key is invalid.
